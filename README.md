# bemineornot_form

Form pemesanan website katalog **bemineornot** oleh Liltz.

Website: [bemineornot form](https://liltzweb.github.io/bemineornot_form/)
Admin Telegram: [@reeumen](https://t.me/reeumen)

## Struktur File
- `index.html`: Struktur form dan tampilan antarmuka
- `styles.css`: Desain visual tiket & kartu exhibit bertema bemineornot
- `site-config.js`: Konfigurasi produk, palet warna, dan seluruh daftar field teks/foto
- `app.js`: Logika interaktif form, kalkulasi harga, validasi, dan fungsi salin clipboard
